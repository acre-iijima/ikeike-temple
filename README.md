# 行け！行け！てんぷる

ラグドールの猫「てんぷる」を操作して、どんどん狭くなる道を走り抜けるゲームです。iPhoneの縦画面で、ブラウザだけで遊べます。

## あそびかた

- 画面の左半分に指を置いてなぞると、そこを中心にした仮想スティックで上下左右に動けます。かべはジャンプではよけられません。
- 画面の右半分をタップするとジャンプして、石・きゅうり・ダンボール・犬・毛糸玉をとびこえられます。
- 星を取るとしばらく無敵になり、障害物をふっとばせます。
- 金の魚を取るとフィーバーになり、魚が集まってきて得点が2倍になります。
- ハートは3つです。全部なくなるとやり直しになります。

## ステージ

全20面で、背景は11種類あります（1〜19面は同じ背景が2面ずつ、最終20面だけ七色にピカピカ光る「ドパドパランド」で専用の曲が流れます）。16〜20面は「激ムズ」です。20面をクリアするとエンディングが見られます。

## 便利なリンク

公開しているURLの最後に、次の文字を付けて開きます。

- `#all` を付けると、全ステージが選べるようになります。
- `#ending` を付けると、すぐにエンディングが始まります。

## ファイル

`index.html` と `audio/` フォルダの曲ファイル（song1〜6.mp4、song1-part2.mp4、ending.mp4）で動きます。GitHubには `index.html` と一緒に `audio/` フォルダの `.mp4` 8つもアップロードしてください（元の `.mp3` は不要です）。絵と効果音はプログラムで作っています。

## 曲

| 曲 | 流れる場面 |
|---|---|
| song1-part2 | タイトル・ステージ選択 |
| song1 | 1〜4面 |
| song2 | 5〜8面 |
| song3 | 9〜12面 |
| song4 | 13〜16面 |
| song5 | 17〜19面 |
| song6 | 20面 |
| ending | エンディング |

曲は面をクリアしても止まらず、曲が変わる面まで続けて流れます（クリアの音の間だけ小さくなります）。ひとやすみ中は止まり、つづけると同じところから再開します。曲の最後まで行くと頭に戻ります。曲ファイルが読めないときは、前のピコピコ音楽が代わりに流れます。

曲ファイルは AAC 96kbps に変換し、前後の無音を削って、音量を -14 LUFS（YouTubeなどと同じくらい）にそろえています。
