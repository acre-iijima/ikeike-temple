# 行け！行け！てんぷる

ラグドールの猫「てんぷる」を操作して、どんどん狭くなる道を走り抜けるゲームです。iPhoneの縦画面で、ブラウザだけで遊べます。

## あそびかた

- ◀ ▶ ボタンで左右に動き、かべをよけます。かべはジャンプではよけられません。
- 「ジャンプ」ボタンで、石・きゅうり・ダンボール・犬・毛糸玉をとびこえます。
- 画面を指でなぞると左右に動き、タップするとジャンプします。
- 金の魚を取るとフィーバーになり、しばらく障害物をふっとばせます。
- ハートは3つです。全部なくなるとやり直しになります。

## ステージ

全20面です。16〜20面は「激ムズ」です。20面をクリアするとエンディングが見られます。

## 便利なリンク

公開しているURLの最後に、次の文字を付けて開きます。

- `#all` を付けると、全ステージが選べるようになります。
- `#ending` を付けると、すぐにエンディングが始まります。

## ファイル

`index.html` だけで動きます。画像や音のファイルはなく、絵も音もすべてプログラムで作っています。
